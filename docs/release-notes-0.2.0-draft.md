## 本次能力

对固定 Git 快照中的 Python/Markdown 默认值、调用签名、配置声明进行证据核对，输出 JSON/Markdown 报告和显式应用的最小文档补丁。不会执行目标项目。提供可配置模型适配器和请求预算、失败记录。

本次扩展构造方法、定义时绑定、字面量参数展开、顺序赋值和嵌套配置覆盖；环境输入、未知展开和运行时 __defaults__ 修改继续保守拒答。Schema 保持 2.0，新程序读取旧完整报告时不重算历史结果，不保证旧程序读取新增字段。
