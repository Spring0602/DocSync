# 当前支持边界

0.2.0 支持 Python 3.12、UTF-8 `.py/.md`、本地 Git 固定快照和显式工作树模式。当前不是全部策划目标已完成的发布版。

已实现的静态检查：

- 公开函数/async 函数与无继承、无元类的简单类方法字面量默认值；区分 None、没有默认值和 UNKNOWN，递归类型敏感比较。
- 代码围栏中的函数调用绑定：必选参数、positional-only、keyword-only、重复绑定、`*args`/`**kwargs` 接口；调用侧出现动态解包时拒答。
- 顶层大写常量、字面量配置字典的值。动态展开/键之后出现的显式键可安全覆盖；显式键之后的动态覆盖、重复赋值、重复字典键、后续更新和动态值保守 UNKNOWN；未找到键不等于键已被删除。
- 唯一模块顶层的直接 `from ... import ...` 重导出，包括链式、相对导入和包 `__init__.py`；证据仍指向原始定义。
- 中英文明确默认句式、含 parameter/default 或 参数/默认值 的 Markdown 表、明确函数标题、相对源码链接、围栏内简单 import 别名和实例赋值。
- 旧版/迁移/条件语境拒绝确定结论；同名歧义拒答；默认值/配置最小补丁，签名问题仅报告。

仍不支持或不承诺：

- 任意自然语言的自动 Claim 抽取。hybrid 对已定位声明作语义复核，不代表模型已阅读整篇文档。
- 任意运行时语义：星号/条件/重绑定等动态导出、继承或元类解析、猴子补丁、复杂数据流、运行时修改对象、复杂实例别名。不会导入或运行目标项目。
- 非 UTF-8、符号链接（包含仓库内链接）、子模块递归、CLI/API 框架适配、多语言。
- 包含转义管道的复杂 Markdown 表、无法解析的伪代码/片段，以及不能明确归属实体的正文。没提取出声明不是“一致”。
- 配置键删除/重命名的历史推断；只扫 HEAD 不推断 introduced_by。

DeepSeek 已完成真实小样本和 20 例七方法开发实验，见 deepseek-suite-20261007.md。受控超时/限流测试与真实请求记录分开。无服务时 hybrid 返回 PARTIAL，规则结果有明确降级标识；纯 LLM 基线返回拒答，不使用规则结果冒充模型结果。

20 个受控种子与 24 个扩展候选均已接收双表并完成披露身份的技术裁决，分别冻结为 seed-dev-v1 和 candidate-dev-v1，均为 dev；不等价于独立人工金标准、真实开源问题或泛化效果。

补丁的自动验证只覆盖支持范围。apply 会核对 SHA-256、canonical 行号/字节区间、确定性 patch ID、完整 diff 和原文；多文件采用全预检、逐文件原子替换与异常回滚，不是掉电安全的跨文件事务，不支持和编辑器并发写入。签名错误可能需要人为选择参数，不能自动编造。

2026-09-30 已核验合并提交的双平台 Core CI 成功，详见 [A 接收与裁决记录](a-acceptance-20260930.md)。这不等于 Documentation consistency 工作流或真实模型实验已验收。团队已确认原创代码和自建样本采用 Apache-2.0；原始 DOCX/PDF 不进入授权及发布范围。
