# DocSync 前端使用与交接

## 先打开看看

1. 把整个 ZIP 解压，不要直接在压缩软件里运行。
2. 打开 DocSync-frontend/DOCsync-demo-video-package。如果收到的是完整项目，直接进入其中的 DOCsync-demo-video-package。
3. 双击 **启动前端.cmd**。
4. 保留弹出的终端窗口。浏览器打开的就是新版首页。
5. 点击“打开当前报告”，先看随包演示。需要自己的数据时，再点右上角“导入 report.json”。
6. 用完后在终端按 Ctrl+C 关闭服务。

如果显示 Python 不存在，需要可用的 Python 3.12 或更新版本。只想看页面时，可直接双击 demo-ui/index.html；不需要 Node、npm 或付费模型。跨页导入推荐使用启动器，直接打开 HTML 的会话行为可能不同。

## 按照这个顺序使用

**看懂一条问题。** 在报告列表点击 connect · timeout，展开“证据对照”：文档写默认值 30，代码定义为 60。这个数字来自演示报告，不是前端自己执行的代码。

**看建议怎么改。** 展开“建议补丁”，看删除行与新增行。点击“下载 diff”保存建议。下载不会修改你的仓库；不能只凭 diff 跳过 DocSync 的 manifest 与前像校验。

**看复扫结果。** 展开“验证记录”，演示包自带对照报告。导入自己的扫描报告后，演示对照不会混入；需自行导入对应的复扫报告。报告可比只意味着可以比较计数，不是网页已经执行修复。

**换成自己的报告。** 导入完整的 report.json，可以搜索路径、参数、原因，或按“确认冲突、不确定、已忽略”等状态筛选。多条结果按页显示；点记录后再看细节。

**去其他页面核对。** “数据”能搜文件；“证据”能切换记录；“运行”显示本次及复扫身份。它们与报告页共用同一份当前数据。恢复演示会清除当前导入缓存。

## 常见情况

| 看到什么 | 应该怎么做 |
| --- | --- |
| 一打开还是旧界面 | 确认打开的是这次解压的目录，再按 Ctrl+F5 |
| 浏览器没自动打开 | 复制终端显示的完整本机 URL，端口每次可能不同 |
| 导入失败 | 选择 CLI 输出的完整 report.json，不是 metrics.json 或 manifest；单文件不超过 10 MB |
| 显示未记录或破折号 | 原报告没有字段，不能理解成零 |
| 显示扫描不完整 | 展开报告诊断，不要宣布所有文档都通过 |
| 显示复扫未完成 | PARTIAL / FAILED 的零告警不是修复通过，先排查诊断并重新扫描 |
| 提示复扫记录无法恢复 | 主报告仍保留，只需重新导入复扫报告，不必重新导入所有资料 |
| 不确定但没有补丁 | 需要补充证据或人工处理，不应自动猜答案 |
| 复扫不兼容 | 核对仓库、基准提交、规则配置和运行 ID；不要拿其他项目的报告比较 |
| 关闭后导入数据不见了 | 会话缓存不是长期存储；重新导入已保存的原始 JSON |
| 提示缓存不可用 | 当前页可继续用，切页可能恢复演示；先导出报告，不要误认是同一份数据 |

## 修改哪里

| 文件 | 负责内容 |
| --- | --- |
| demo-ui/styles.css | 报告页布局、字体、颜色、磨砂图标与手机适配 |
| demo-ui/app.js | 报告搜索、筛选、选择、证据和 diff、复扫导入 |
| demo-ui/portal.css 和 portal.js | 首页以及数据、证据、运行页 |
| demo-ui/report-store.js | 所有页面共用的数据结构、统计与缓存契约 |
| demo-ui/*.html | 页面结构与静态文案 |
| demo-ui/demo-data.js | 原始演示报告；只能用真实运行结果更新 |
| scripts/serve_frontend.py | 本地只读预览服务，不是扫描接口 |

配色集中在 CSS 的 :root 变量。常规界面使用系统无衬线字体；代码和哈希使用等宽字体。图标为 SVG，磨砂效果来自 CSS，不必另找图片或在线图标服务。

## 发给队友

优先发送由项目脚本生成的 **DocSync 前端交接 ZIP**。它包含页面、演示工件、启动器、使用说明和 LICENSE，不包含你的私人标注、真实导入报告、密钥、虚拟环境或整份项目源码。

收到后保持目录结构，按本页步骤打开。如果队友还要执行扫描或修改 Python 核心，需要另取主项目源码并安装 Python 3.12 依赖；前端交接包不包含扫描引擎。

版本是本地改动交接，不代表已推送 GitHub。团队审核和仓库合并由项目负责人决定。
