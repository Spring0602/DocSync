开始使用

第一次打开时会载入随包演示。

  1. 1

    先看一个案例

    打开报告，点选问题，再查看对应证据和补丁。

    进入报告 →
  2. 2

    扫描自己的仓库

    安装 DocSync 后，在终端运行下方命令；将路径替换为自己的 Git 仓库，每次使用新的输出目录。

    docsync scan --repo /path/to/repo --out runs/check
  3. 3

    导入并核对结果

    在报告页选择生成的 report.json。补丁经人工审阅后在 CLI 中应用，再导入复扫报告。
